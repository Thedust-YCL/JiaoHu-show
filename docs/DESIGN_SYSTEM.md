# AGENT / ZERO — DESIGN SYSTEM

> **AZ-DESIGN v1.0｜配套 PRD v0.7｜2026-10-14**  
> 状态：**品牌方向、核心造型与高保真视觉基线冻结**。实现参数可在 M0.1 实测后微调；不可擅自改变视觉身份、产品方向或纯前端架构。

## 0. 核心设计宣言

> **P0 技术红线**：本设计必须在**纯前端、无后端、无真实 AI API**的静态网站中实现。Three.js/GSAP 动画、2D 面板和视觉降级均在浏览器完成。参考 `PRD.md` 的完整技术契约。


**关键词**：黑曜虚空、科研终端、神经宇宙、精密机械、数字生命、克制电影感。

观感目标不是常规 AI SaaS 官网，也不是整屏蓝紫发光粒子：

- **安静的空间 + 显著的中央实体**：背景足够暗，用户的注意力自然落在 AZ-CORE 01 上。
- **科学仪器般的精确感**：连接、刻度、端口、标注都有意义，拒绝随机数据文字。
- **低动态待机 + 强事件反馈**：静止也有美感；只有真实交互事件触发显著光效。
- **可阅读、可操作**：所有重要正文由 HTML 呈现，清晰、可选中、有焦点状态。
- **视觉服务于认知**：知识图谱表达概念关系；系统图表达当前配置；执行图表达事件路径，三者不可混淆。

## 1. 品牌规范

### 1.1 名称与语言

- 产品全称：**AGENT / ZERO**。
- 小尺寸识别符：**A/0**（斜杠对应状态转换/边界，零对应初始核心）。
- 英文副标题：**AN INTERACTIVE ATLAS OF AGENTIC AI**。
- 标语：**FROM LANGUAGE TO ACTION.**；中文：**从语言，到行动。**
- 主界面语言：中文解释 + 简洁英文系统标签；英文不得取代必要的中文教学说明。
- 不采用机器人头、聊天气泡、通用魔法星星等泛 AI 品牌图形。

### 1.2 Logo 用法

- 导航栏左侧 `A/0` + `AGENT / ZERO`，空白处不重复覆盖巨大水印。
- 开场中完整品牌可单独出现，停留足以阅读，随后自然收缩到左上角。
- 如设计图形版标识，必须保持切角/几何/精密刻度语言；勿过度装饰。
- 在极窄视图只保留 `A/0` 与 accessible name，不强行压缩完整文字。

| `color.attention` | `#F0BD78` | 焦点、用户待确认状态 |

允许使用色彩的 alpha 变体、材质细微明暗变化，但不可为每个章节任意引入一套霓虹主色。重要状态必须伴随文字/图标/线型，不能只靠颜色。

### 2.2 字体

| 层级 | 字体方向 | 大小参考 | 注意 |
|---|---|---|---|
| Logo / 章节大标题 | Inter 类现代无衬线 | 52–72px | 极简、较宽字距；按移动端缩放 |
| 页面标题 | Inter + Noto Sans SC | 32–44px | 视觉层级优先 |
| 功能标题 | Inter + Noto Sans SC | 18–22px | 清晰，不用花体 |
| 解释正文 | Noto Sans SC / 系统中文无衬线 | 15–16px | 舒适行高约 1.5–1.7 |
| 参数、日志 | JetBrains Mono / 合理等宽回退 | 13–14px | 数据可复制、可选中 |
| 微型系统标签 | 等宽 | 12–13px | 不用于大量正文 |

需要核查字体许可证，静态打包必要字体子集；不可从本地机器复制未经授权的字体，更不可只依赖远程 Google Fonts 在线加载。所有中文正文应优先可读，不刻意全大写。

### 2.3 空间与组件

- 全站基础空间尺度：4px；常规组件间距以 8px 倍数组织；区块间距 16–24px。
- 一级面板：1px 边框、6–8px 圆角、低对比近黑半透明背景。
- 弹层/较大容器：允许最多约 12px 圆角；避免大面积毛玻璃与强背景模糊。
- 分割线应精细，层级通过留白与边框表达，不依赖大量实心卡片。
- 坐标、标尺、十字准星、序号只在可解释位置出现；不生成无意义乱码。
- UI 动画不能影响输入焦点或挡住按钮点击。

### 2.4 状态视觉语法

| 意义 | 表现 |
|---|---|
| 静态可用 | 中性色金属边缘、清晰文字 |
| Hover / Focus | 局部提亮、精细外描边、明显键盘焦点 |
| Selected | Amber 小型定位标记或高亮轮廓，不完全淹没原色 |
| Activated / Connected | Cyan 连接线与可见状态文字 |
| Verified | Green 符号 + “已核验” |
| Disabled | 降低亮度并显示“已禁用”，不能只用透明度 |
| Blocked / Error | Red 局部中断 + 明确原因，可定位修复入口 |
| Simulated | `SIMULATED / 本地模拟` 常驻适当位置 |

## 3. 主体视觉：AZ-CORE 01

### 3.1 造型冻结

**机械式天体仪轨道 + 黑曜几何奇点 + 少量神经式数据流**。

中心是一颗多面体，不是普通完美球体；最外层为精密空间机械装置，不是一直旋转的发光魔法阵。几何结构在 Story、Hub、Constructor 和 Execution 保持同一身份，不为不同页面换一颗完全不同的模型。

### 3.2 几何分层

| 层 | 造型 | 含义（仅教学性视觉映射） |
|---|---|---|
| L0 | 黑曜多面体，切面外壳与内部冷白能量 | 模型核心 |
| L1 | 内部约束环与细刻度 | 核心边界 |
| L2 | 三组不同倾角的金属机械轨道 | 可扩展的结构空间 |
| L3 | 轨道接口、装配定位点 | 外部能力端口 |
| L4 | 低密度数据脉冲、外部测量线 | 活动路径与运行反馈 |

该“层级”是艺术与交互信息设计，不代表软件架构中必须恰好存在五层实体。

### 3.3 归一化几何建议值

- 场景中心：`(0, 0, 0)`，统一世界单位。
- 主核心参考半径：`1.00`；内轨：`1.45`；中轨：`1.90`；外轨：`2.40`。
- 接口总体分布半径：`2.50–2.90`，避免遮挡核心正面辨识度。
- 三组主要轨道倾角初值：`−35°`、`25°`、`65°`，需要通过真实 3D 模型调整可见性。
- 主摄像机 FOV 初值：约 `40°`；正面标准视角可绕核心轻微偏轴，以展示深度。
- 模块外形：切角矩形或六角机械接口，不能像普通圆角气泡悬浮在球体表面。
- 参数是开发初值，**结构层次、运动方式、形象辨识度**为冻结项，非每个数字都不可调整。

### 3.4 材质

1. **Obsidian Shell**：深石墨金属，适度粗糙、有棱面明暗与极细金属边缘。
2. **Gimbal Frame**：哑光钛灰，纤细高光、不同轨道互相穿插但无明显穿模。
3. **Energy Channels**：内核裂隙为冷白到 Cyan 的能量光，常态不过曝。
4. **Data Pulses**：连接时短暂沿线路流动，不在待机状态持续爆发。

避免：强镜面反射、大面积 Bloom、到处飘的随机字符、全屏闪电、快速旋转、使用第三方参考图充当页面最终素材。

### 3.5 基础光照与后期

- 主光用于体现多面体切面、轨道厚度及材质层次；辅助冷色边缘光形成空间轮廓。
- Bloom 强度应受控，仅在能量裂缝和确有意义的活跃连接上出现。
- 多层透明粒子影响移动端性能，优先几何线条和材质表达。
- 在光效关闭/降低的情况下，AZ-CORE 仍能通过剪影和轮廓辨认。

## 4. AZ-CORE 动态状态

| 状态 | 主要动画 |
|---|---|
| `DORMANT` | 核心暗淡，轨道静止或近乎静止 |
| `BOOTING` | 核心发亮，三组机械轨道依次装配 |
| `IDLE` | 缓慢相对旋转，少量能量呼吸 |
| `FOCUSED` | 摄像机靠近，被选结构局部高亮 |
| `PREVIEW` | 半透明模块、兼容接口、预连接轨迹 |
| `ASSEMBLING` | 模块沿明确曲线路径进入目标接口 |
| `RUNNING` | 按**真实模拟事件**显示数据流 |
| `PAUSED` | 活动脉冲冻结；允许查看信息 |
| `ERROR` | 局部通道中断、颜色/图标/原因明确 |

M0.1 只需落实 `DORMANT → BOOTING → IDLE → FOCUSED`；装配、运行等状态预留 API 与视觉接口，不可在 M0.1 用假结果冒充实现。

待机运动参数初值：轨道 A 约 `+0.5°/s`、B 约 `−0.35°/s`、C 约 `+0.2°/s`，核心自身更缓慢。若渲染停止更新应静止在合理姿态；用户主动拖动时暂停自动旋转。

## 5. 电影化开场：AZ / INITIALIZATION SEQUENCE

设计目标：**一个连续场景从纯黑虚空逐步转化为可以操作的系统主界面。** 不是先播视频再瞬切另一个网页。

| 镜头 | 时间（初值） | 视觉 | 摄像机 / 字幕 |
|---|---|---|---|
| 01 THE VOID | 0.0–2.0s | 黑暗、一点微光、少量切面轮廓 | `(0,0,12)` 向前慢推，无过度粒子 |
| 02 AWAKEN | 2.0–4.2s | 多面体裂缝依次亮起 | `(1.5,0.8,8.5)` 轻微环绕 |
| 03 ASSEMBLE | 4.2–7.2s | 三组机械轨道分步拼合、端口依次点亮 | `(2.8,1.4,8.0)` 展示空间深度 |
| 04 IDENTIFY | 7.2–9.0s | 核心稳定、测量标尺/品牌浮现 | `(0.6,0.5,8.0)` 回正；`AGENT / ZERO` / `FROM LANGUAGE TO ACTION.` |
| 05 ENTER SYSTEM | 9.0–11.0s | 镜头后撤、Hub 面板渐入 | 摄像机回到自适应主工作区，不重建第二颗核心 |

- 总时长约 8–12s，表中 11s 是目标节奏。
- 默认缓入缓出，非剧情必要不使用震屏、过强景深或运动模糊。
- 字出现时适度降低背景运动，保留阅读时间。
- **Skip 必须始终可见**，触发后所有开场时间线中止并直接设到稳定 `IDLE + HUB` 的确定性状态。
- 首次访问播放（本地标记）；再次访问默认直达 Hub；菜单可重播。
- 遵守 `prefers-reduced-motion`，采用极短淡入或静态图代替大幅运镜。
- WebGL 不可用时，显示 2D 核心/有效导航，不强制尝试开场三维渲染。

## 6. Control Hub 桌面布局

**1440×900 为首要设计基准**，同时检查 1920×1080 与常见 16:10 笔记本比例。

| 分区 | 初始尺寸 | 作用 |
|---|---|---|
| 顶部系统导航 | 高 64px | `A/0`、模式导航、状态、重播 |
| 左侧导航/能力架 | 宽约 208–224px | Story / Atlas / Lab / Constructor 入口，后续可选择能力 |
| 中央舞台 | 自适应剩余空间 | AZ-CORE、空间交互与视觉焦点 |
| 右侧 Inspector | 宽约 320–340px | 核心/模块状态、参数、概念说明 |
| 底部区域 | 高约 140–160px | M0.1 系统日志/状态；后续 Event Timeline |
| 主要布局间隙 | 16–24px | 保证深色空间感、避免面板拥挤 |

- 3D 对象不贴满画布，须能看清完整轨道及预留模块装配空间。
- 面板布局应稳定，文本长度变化不能使 3D 画布剧烈跳动。
- 右侧 Inspector 可收起；主内容结构不被装饰层盖住。
- M0.1 未实现的章节入口标注未开放或禁用，不做无功能点击区。

## 7. 3D + 2D 混合视图

- Assembly：中央实体为主，选择模块、装配预览与端口显示。后续有左侧模块架和右侧 Inspector。
- Inspector/System：相同配置数据绘制成高精度 2D 架构图，参数、权限、事件详情由普通 UI 控件呈现。
- 视图切换是**同一个系统状态的表现变换**；改变一个视图的配置，应更新其他视图。
- M0.1 可只展示 2D 架构**视觉预览**，但不得假装已支持完整装配与模拟。

## 8. 装配动效视觉规则（供 M0.2 使用）

- **点击默认路径**：选中模块 → 兼容端口亮起 → 半透明预览 → 点击确认 → 模块沿轨道装配 → Inspector 更新配置 → 状态确认为 Ready/Unconfigured。
- **可选引导拖拽**：只允许拖到兼容端口，具备吸附范围；不兼容有文字提示，释放后回原处；Esc 取消；禁用状态不能拖出虚假的成功连接。
- 添加/移除/禁用时，3D 核心、2D 图谱和配置显示应来自**同一逻辑状态**。
- 视觉层的 `Selected`、`Hover`、`Dragging` 不改变业务模块的逻辑身份。

## 9. Atlas、Lab 与 Execution 动效语言

| 动画词汇 | 表达的含义 |
|---|---|
| ASSEMBLE | 模块建立系统组成关系 |
| CONNECT | 有效连接建立 |
| PULSE | 实际模拟数据/调用正在传递 |
| EXPAND | 概念节点展开详情 |
| ORBIT | 系统稳定待机 |
| FRACTURE | 局部执行失败/断连 |
| RECONSTRUCT | 重试、修复或结构重组 |

**知识星图是语义网，不是装饰性节点雨**。建议连接关系 `USES`、`PART_OF`、`RELATED`、`CONTRASTS` 有方向、线型、说明和图例。点击概念不自动修改 Agent 配置；可以跳至相应的构建器模块并高亮。

执行播放由事件序列统一驱动：请求发生→连接脉冲→工具返回→证据更新。暂停时冻结运行数据流，检查操作仍可用。视觉转场时间不得改变模拟逻辑。

## 10. Motion Timing 与交互反馈

| 动效范围 | 时间初值 | 特性 |
|---|---|---|
| Hover / Press / Focus | 150–300ms | 立即开始反馈，强调控制感 |
| 装配与模块结构变化 | 400–800ms | 有开始、到达与明确结束态 |
| 章节/空间切换 | 1–2s | 镜头连续，不让用户常规操作被阻塞 |
| Boot | 8–12s | 仅首访默认播放，可跳过、可重播 |

- 同时发生的动画应有主次，核心活动时降低环境杂音。
- 重要内容出现时减少运动；不得用动效制造不存在的工具调用或执行结果。
- 用户暂停、跳过或切页，GSAP/Three 时间线应安全结束或清理，避免出现残留运动。

## 11. 响应式与无障碍

| 视口宽度 | 方案 |
|---|---|
| ≥1440px | 左/中/右三工作区 + 底部状态区 |
| 1024–1439px | 缩窄侧栏，可折叠 Inspector |
| 768–1023px | 主舞台优先，侧面板变抽屉 |
| <768px | 单列/底部抽屉、点击优先、可简化 3D 或回退 2D |

- 键盘焦点明显，所有操作不以细粒度拖拽作为唯一入口。
- `Esc` 取消拖拽/关闭浮层、Tab 可抵达功能控件、按钮有可读标签。
- 正文对比度目标不低于 4.5:1，大文字不低于 3:1；具体组合在实现阶段实际测量。
- 用户系统开启减少动态效果时，禁止强制空间运镜、持续旋转和大幅闪烁。
- WebGL 缺失/报错时，不显示永久黑屏；回退可访问的 2D 核心、系统说明和导航。

## 12. 性能与资源制作建议

- 目标桌面平稳呈现约 60fps，低档降级至少维持可操作体验；**实测验收，不凭描述宣称**。
- 减少多重后期 Bloom、高粒子数量、透明叠层、巨大贴图和无意义循环更新。
- 在画面不可见/无需运动时降低或停止渲染；必要时以设备像素比/后期效果分档。
- Geometry、material、texture、framebuffer 有清理路径，模式切换避免内存增长。
- 背景图、图标、字体和 3D 模型都应能随静态产物离线打包；不依赖 CDN。
- 不把通过搜索获取的第三方图片直接作为最终艺术资产，核心应原创生成几何或具有合法来源的本地资源。

| 帧号 | 画面 | 主要检查 |
|---|---|---|
| F01 | THE VOID | 画面干净、纯黑层次、悬念与光点位置 |

## 14. 版本冻结规则
