# M3.2 性能与全项目质量验收交接

日期：2026-10-27。此处仅记录下一阶段待办，不在 M3.1 实施完整性能专项。M3.1 保留同一配置/Runtime/比较逻辑，新增能力限于表现、导航、反馈和键盘路径。

| 优先级 | 专项 | 可复查目标 / 验收方法 | M3.1 覆盖边界 |
|---|---|---|---|
| P1 | 浏览器矩阵 | Chrome、Edge、Firefox、Safari 的深链刷新、IndexedDB、下载、inert/dialog、WebGL/减少动态 | 本轮仅真实 Chrome 无头桌面模拟 CSS 视口，其他浏览器 NOT RUN |
| P1 | 真实设备 | iOS/Android 真机、触控/软键盘、横竖屏、浏览器地址栏变化和低端 GPU | 本轮未声称真机覆盖；360–430px 为桌面浏览器模拟 |
| P1 | 3D 渲染剖析 | 真 GPU 建立 FPS/长帧/DPR/三角形/绘制调用/透明层预算；后台暂停与隐藏面板采样 | 本轮保留模型和单场景，SwiftShader 数值不代表真实 GPU 性能 |
| P1 | 内存/资源 | 反复 Boot/知识/运行/A/B 100 次切换；堆快照、geometry/material/texture 与监听器增长 | 本轮只验证关键往返，不宣称长时资源泄漏检查通过 |
| P1 | 全链路自动化 | 固定版本浏览器/无头配置、串行隔离构建、条件等待，覆盖所有主要入口与故障 | 本轮沿用 CDP；已修视口未稳定与 Enter 文本注入等测试前提问题 |
| P1 | 数据边界审计 | 配置/历史/档案 schema 和迁移、XSS、导出转义、容量/配额、下载阻止、不同源与 file URL | 本轮回归既有数据隔离与损坏保留；不是完整发布前安全认证 |
| P2 | 加载与包体 | 基于真实构建产物建立 JS/CSS/gzip 预算，评估按需加载、资源缓存与离线单文件取舍 | 未引入新依赖；没有在本阶段做分包、Service Worker 或完整离线 PWA |
| P2 | 辅助技术 | NVDA/VoiceOver 的路由标题、审批播报、图谱列表、表单错误和多层弹窗；检查200%缩放 | 本轮验证键盘、焦点、inert/ARIA 和减少动态；完整读屏与认证 NOT RUN |
| P2 | 视觉/长文本矩阵 | 更长中文/英文配置名、极端日志/来源ID、200%字体、超长报告与大档案列表 | 本轮共享换行、局部表横滚、基础多视口截图；大规模视觉快照待扩展 |
| P2 | 来源维护 | 按内容阶段规范重新核验技术外链和版本，保留 reviewed/draft 的诚实标记 | M3.1 未新增知识内容；不把本次视觉回归当成外部来源重新核验 |

正式发布和部署属于 M3.3。本轮未推送、未上线；不以本清单表示这些专项已验收。
