# AGENT / ZERO 用户指南（发布候选草案）

这是一个本地教学模拟：示例校园公告是虚构资料，界面不会调用真实模型或进行联网研究。参考资料链接需由用户主动打开。

1. 打开首页，等待开场或选择「跳过开场」；也可按 Esc。控制台提供各工作区入口。
2. 从 Story 的六章开始，也可在 Atlas 搜索概念、阅读解释和关联。六章分别介绍智能、上下文、连接、知识、运行及可靠性；每章可进入对应的 Token、Context、Tool Calling/MCP、Knowledge、Runtime、Reliability 实验。
3. 在实验中修改参数并观察结果；学习活动和进度可在 Knowledge Journal 查看。活动记录与学习进度有各自的清除操作，操作前阅读确认提示。
4. 打开 Constructor 的「本地配置与示例」，加载 Starter 或 Evidence First。点击模块装配并在 Inspector 编辑，用预检查看缺失依赖或权限；保存具名配置以便之后加载。
5. 从预检进入 Runtime，选择本地场景并单步或连续运行；必要时暂停、继续、批准或拒绝。检查事件、证据和报告的来源；审批是模拟，不能当成真实安全控制。
6. 打开 A/B 对比，选择或复制两份配置，设置共同场景和种子，运行后检查指标与引用。可保存实验档案、重开、重跑或下载 Markdown。

数据仅存于当前浏览器及站点源，清理站点数据、换浏览器或设备可能丢失。Journal 最多 200 条活动，Runtime 最近 5 条，实验档案最多 12 条／20 MiB，单条最多 3 MiB。保存失败或数据损坏时先阅读提示并保留原始数据；不要盲目清除所有站点数据。静态站的实验代码按需加载，断网且代码块未缓存时无法首次打开；可使用构建生成的根目录离线单文件。无 WebGL 时可使用二维视图；具体浏览器与设备覆盖见发布审计。
