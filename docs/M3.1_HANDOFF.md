### 4.2 开场与 AZ-CORE 01

- 保留同一机械轨道／几何核心，没有替换建模身份、添加假联网／假执行动画。

- Constructor 在 Runtime 开着时改变，不得覆盖正在查看的历史运行快照。
- `executionCore.js` 增加纯表现适配，兼容旧事件 `id/message` 与 M2 Runtime `eventId/reason` 等字段；无事件时显示“就绪”，不显示 undefined 或上次事件。
- 新运行 render 始终清理旧 caption／SVG 状态（独立审查 R01）。
- **新增更严格的真实快照／事件／Inspector 一致性浏览器断言 A10-runtime-snapshot 尚未运行**，见第 7 节。

### 4.4 导航与上下文

- 继续使用现有 hash 路由，补齐真正的 `#/execution`、`#/report`，不再将旧执行台写成 `#/hub`。

- 深链测试使用新的 query 触发实际 document load，避免只改 hash 后误把旧的 `__AZ` 当新页面；不要 navigate 后立刻 reload 造成加载竞态。
- `waitReady` 看 app ready；减少动态检查用实际 phase 的有界条件等待，不依靠任意 800ms 或帧率。
- M31 每次写同一个 `browser-results.json`／`browser-summary.json`，不同 flags 会覆盖，必须立即复制为独立证据文件。
- M21 旧 JSON 可能未被被中止的运行覆盖，要用 `--report=` 新路径，避免误读。
- 本次暂停前活跃工具会话为 M21 `62292` 和 M31 `35632`：M31 已自然结束 exit 0；M21 已 Ctrl+C 中止 exit 1。停止后探测两个专用浏览器调试端口均无可访问实例，没有留下待继续的测试会话。
