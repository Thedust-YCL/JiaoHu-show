## 0. 一句话任务

**仅制作 AGENT / ZERO 的 M0.1 高保真视觉基础原型**：一套原创、可实时交互的 AZ-CORE 01 三维核心，一段可跳过的五镜头启动序列，以及能够自然承接开场的高保真 Control Hub。完成基础选中/旋转/缩放/Inspector 预览、响应式与静态部署验证，**不要开发正式研究模拟引擎和六章内容**。

目标不是做普通后台页面，而是形成一个**静止时也精密高级、运动时具有电影感且可操作**的完整小体验。

## 1. 不可变更约束（P0）

1. **纯前端**：运行时全部业务逻辑在浏览器执行。
2. **禁止后端**：不得引入 Flask、FastAPI、Express 业务服务器、Next API Routes、Serverless Functions、云数据库或任何业务后台。
3. **禁止远程 AI**：不请求任何外部 LLM API、不要求 API Key、不实现真实 Agent/MCP/工具调用。
4. **可静态部署**：使用 React + TypeScript + Vite（或同等纯前端构建）；`npm run build` 应输出可单独托管的静态 `dist/`。
5. **必需资源本地打包**：字体、图标、模型、代码与必要静态数据不得依赖运行时第三方 CDN。
6. **真实功能与预览分离**：本阶段不实现的 Story/Atlas/Lab/Constructor 功能要有清晰“未开放/后续阶段”状态，不能制造能点击却没有行为的假按钮。
7. **原型的中枢不可造假**：旋转、选中、重置等交互必须真的控制同一套 3D 核心/状态，不能只播放视频或贴图冒充 3D。
8. **禁止自行扩大范围**：不要抢先实现模拟器、研究报告、Skills/MCP 业务功能或全部知识章节。

## 3. 视觉交付的“必须像什么”

- **主色调**：`#07090D` Void；`#10151D` Panel；`#17212C` Raised；`#77D8EC` Signal；`#F0BD78` Attention；`#80D9B4` Verified；`#FF8585` Error。
- **中央主角**：机械天体仪轨道 + 黑曜几何核 + 少量神经式数据流；不得简化为单个发光球体。
- **风格**：黑曜虚空 × 专业科研控制台 × 神经星图，偏精密的未来机械设备，而不是花哨的泛 AI SaaS 落地页。
- **材质**：深石墨金属切面、哑光钛灰机械环、克制的 Cyan 冷白能量裂缝。
- **文字**：开场品牌和少量口号；Control Hub 标题、状态与 Inspector 正文可读。重要文字使用 HTML 而不是贴到 3D Canvas 上。
- **动效**：平稳缓入缓出；待机极慢；不能高频闪烁、遮挡文字、滥用 Bloom。
- **静态审美也要过关**：看 F04 完整核心、F05 控制台两张定格图，即能感受到明显的原创性与结构感。

详见 `DESIGN_SYSTEM.md`，不得自行用整套不同配色和风格覆盖。

## 4. AZ-CORE 01 制作要求

### 4.1 几何要求

- 中央核心为可识别棱面的多面体，外层深色硬质切面，可露出内部冷白能量；不能用单纯球体代替。
- 三组**真正具有不同空间倾角**的精密环形轨道，弧线相交时应有合理前后遮挡、厚度与空间层次。
- 轨道外围保留可以扩展为模块接口的位置；M0.1 可为静态机械端口，不必实现装配逻辑。
- 数据流为局部、低密度装饰，仅以轻微呼吸或短暂脉冲表现，不承担虚构业务消息。
- 三维材质即使不开 Bloom，剪影也清晰。场景背景不被粒子覆盖。

### 4.2 建模初始参数（允许实测微调）

```text
Scene center: (0, 0, 0)
Core radius: ~1.00
Ring 1 radius: ~1.45
Ring 2 radius: ~1.90
Ring 3 radius: ~2.40
Port range: ~2.50 to 2.90
Ring orientations (reference): -35°, +25°, +65°
Camera FOV: ~40°
```

优先将核心切面、轨道、接口、能量通道拆为独立组件，后续 M0.2 要以此为基础增加装配状态。几何应尽量程序化或使用拥有可用授权的本地素材；不把参考图放进 Canvas 当作最终效果。

### 4.3 可运行视觉状态（M0.1）

- `DORMANT`：暗淡，轨道基本静止。
- `BOOTING`：核心唤醒、轨道装配。
- `IDLE`：稳定待机，微弱相对转动。
- `FOCUSED`：选中对应部件，局部高亮并聚焦镜头。

`PREVIEW`、`ASSEMBLING`、`RUNNING`、`PAUSED`、`ERROR` 等可预留状态类型，但本轮**不实现虚假的模拟行为**。

### 5.1 播放行为

- 默认首次访问播放；本地存储首访完成标记；再次访问直接进 Hub。
- 开场全过程有可点击、可键盘聚焦的 `SKIP`；菜单含 `REPLAY INTRO`。
- Skip 必须**取消/结束全部相关动画时间线**，设置到唯一稳定的 `HUB + IDLE` 终态；不允许半装配、光效残留、镜头漂移。
- 结束镜头与 Hub 使用**同一套核心对象和相机状态**，不是硬切到另一张图片/另一颗球。
- `prefers-reduced-motion` 时，以静态或简短淡入进入 Hub；不强制看强运镜。
- 页面隐藏/组件卸载时清理动画与事件订阅。

### 5.2 快速验收路径

1. 首次访问看完整开场，观察轨道装配和 UI 自然浮现。
2. 清除本地首访标记后再次访问，在任意 Shot 点击 Skip，应立即进入稳定 Hub。
3. 刷新后不应每次强制观看；点击 Replay 可以完整重看。
4. 快速连续触发 Skip/Replay，不能出现多次重叠核心或动画残留。

│ STORY       │                               │                        │
│ ATLAS       │                               │                        │

├─────────────┴───────────────────────────────┴────────────────────────┤

未完成 Story/Atlas/Lab/Constructor 的具体内容时，标记“Coming in later milestone”；如果有入口展示说明面板，该面板需要能返回且保持正常键盘操作。

### 6.2 交互细则

1. **旋转**：鼠标或触摸拖动核心，受控 Orbit Controls，限制极端翻转和空转；停止拖动后渐进恢复低强度待机效果。
2. **缩放**：滚轮缩放受最小/最大距离约束；不会穿入模型或缩到失去主体。
3. **选中**：点击核心或明确可选部件，使其高亮、更新 Inspector 并轻微调焦；重复点击或点击背景可以退出。
4. **重置**：清晰可发现的 `RESET VIEW` 控件，将视角还原标准镜位。
5. **视图预览**：若制作 2D 结构视图，明确只用于显示视觉架构雏形，不包含假装可运行的模块参数。
6. **状态一致**：唯一选中状态同时驱动 Canvas 高亮和 Inspector 文案，不能分别维护两套临时真假状态。
7. **操作反馈**：按钮按下可立即看到反应，长动画期间应允许退出而非锁死界面。

## 7. 响应式、降级与静态构建

### 7.1 视口检查

至少检查：1440×900、1920×1080、1280×800、1024×768、390×844。

- ≥1440：完整左/中/右布局。
- 1024–1439：侧栏适度缩窄，Inspector 可收合。
- 768–1023：主画布优先，导航/Inspector 可变抽屉。
- <768：避免横向溢出；简化核心与面板并提供可用导航及信息访问。

### 7.2 降级检查

- `prefers-reduced-motion`：开场不强制旋转运镜、待机不过度运动，仍可操作。
- WebGL 不可用/上下文创建失败：**不是黑屏**；以 2D/SVG 示意核心和可访问的导航/说明作为兜底。
- 降低渲染性能：按设备反馈减少后期光效、粒子数量、分辨率，避免整页滚动卡顿。
- 页面无关键业务网络请求；依赖静态站点资源下载即可渲染。本阶段不是强制完整离线 PWA，不要额外造服务器。

### 7.3 静态部署检查

- 项目可执行 `npm install`、`npm run dev`、`npm run build`、`npm run preview`（具体以 package scripts 为准）。
- `dist/` 不依赖服务器端动态运行时；确保 Vite `base` 配置适用于 GitHub Pages 仓库子路径。
- 校验页面资源路径、字体、图标、模型是否正常加载，刷新后不会出现资源 404。
- 如果采用前端路由，优先选择适配静态部署的方式或增加正确的静态回退；不要引入 API Route 解决页面刷新。

## 8. 工程分层与质量要求

建议维持以下边界（具体文件名可以按项目组织）：

```text
src/
  app/                   # App shell、导航和偏好设置
  brand/                 # Logo、文字和基本主题
  scenes/
    core/                # AZ-CORE geometry/material/light
    camera/              # 机位、旋转和重置
    intro/               # five-shot timeline
    fallback/            # SVG / 2D visual
  components/
    layout/              # Top bar/left/right/bottom panels
    ui/                  # 按钮、标签、Inspector primitives
  state/                 # scene mode, selection, preferences
  styles/                # Tokens, typography, responsive
```

- 不将全部 Three.js 几何、GSAP 时间轴和 React 页面放到单一巨大组件。
- 统一管理时间线、动画帧、事件监听和 WebGL 资源释放。
- 尽量把视觉状态声明化，不直接散落硬编码 DOM 样式切换。
- M0.1 留下明确扩展点给 M0.2 装配逻辑，但不得为了所谓扩展性提前实现全套模拟业务。
- 复杂材质、shader 必须有合理降级，保证维护性。
